# Хэш-ссылки для калькуляторов iRepair Store

Чтобы открыть нужную вкладку сразу — добавь хэш к URL страницы, где размещён блок.

**Формат:** `https://irepair-store.ru/СТРАНИЦА/#ХЭШ`

## Как это работает

- При клике на вкладку URL страницы автоматически обновляется (без перезагрузки).
- При открытии ссылки с хэшем нужная вкладка активируется сразу.
- При переходе по новой хэш-ссылке на той же открытой странице вкладка переключается.
- Меню CS-Cart подсвечивает только тот пункт, чей хэш совпадает с текущим.
