# SEO-текст категории iRepair-Store (с исследованием)

Скилл создаёт полноценный SEO-текст категории для **irepair-store.ru** (Москва) с обязательным этапом исследования: частотные запросы, органическая выдача, конкуренты. Итог — HTML-файл по эталону и согласованные H1, Title, Description.

**Геопривязка**: Москва (все запросы и тексты — с учётом «Москва», «в Москве», «купить в Москве» и т.п.).

---

## Когда применять

- Пользователь просит создать или доработать SEO-описание категории для iRepair-Store.
- Упоминается категория товаров (MacBook Pro, AirPods, аксессуары для iPhone и т.д.) и нужен текст для продвижения.

---

## Обязательный порядок действий

### Этап 1. Исследование запросов и выдачи

Перед генерацией текста выполнить:

1. **Частотные запросы**  
   Через веб-поиск подобрать самые частотные/релевантные запросы по теме категории и Москве, например:
   - «[название категории] купить Москва»
   - «[название категории] цена Москва»
   - «[название категории] заказать»
   - «купить [название категории] в Москве»

2. **Органическая выдача**  
   Поискать в Google и Яндекс по 1–2 основным запросам (с «Москва» / «купить»), зафиксировать:
   - Какие типы страниц в топе (категория, карточка, статья).
   - Какие формулировки встречаются в заголовках и сниппетах.

3. **Топ-5 конкурентов**  
   По результатам выдачи определить 5 сайтов-конкурентов (магазины техники Apple / электроники в Москве). Для каждого по возможности:
   - Открыть страницу категории (через mcp_web_fetch или веб-поиск).
   - Выписать: **Title**, **meta description**, **H1**, структуру заголовков (H2, H3) и объём текста на странице.
   - Кратко зафиксировать, какие фразы и блоки они используют (преимущества, доставка, гарантия и т.д.).

Результат этапа: список ключевых запросов для вхождения в текст + краткая сводка по конкурентам (мета, структура, идеи для формулировок). Эту сводку использовать при написании текста.

---

### Этап 2. Нужны ли изображения

- Если по эталону или по смыслу категории в блоке должны быть изображения (например, фото товара или схемы) — **до генерации финального HTML** сообщить пользователю:
  - какие именно изображения нужны (назначение, примеры подписей);
  - в каких местах блока они будут (после какого абзаца или секции).
- После того как пользователь предоставит файлы или URL — вставить их в разметку и сохранить файл.

Если изображения не требуются — переходить к этапу 3 без запроса.

---

### Этап 3. Генерация текста и файла

1. **Структура и стили**  
   Использовать правило из `.cursor/rules/category-seo-irepair.mdc` и эталон `категории/AirPods Max.html`:
   - Один блок `<style>` с классами `.irepair-category-seo`, `.irepair-seo-inner`, `.irepair-seo-collapse`, `.irepair-seo-toggle` и т.д. (стиль Apple: #f5f5f7, #1d1d1f, #0071e3, -apple-system).
   - Сворачивание: контент в `.irepair-seo-collapse`, по умолчанию 200px, кнопка «Показать ещё»/«Свернуть», класс `is-expanded` на `.irepair-category-seo`.
   - Один инлайновый `<script>` для переключения по клику на `.irepair-seo-toggle` (querySelectorAll + closest для нескольких блоков).

2. **SEO и разметка**  
   - Заголовки: только **H2** (H1 остаётся у названия категории в CS Cart). У каждого `<section>` — `aria-labelledby="h2-..."`, у `<h2>` — уникальный `id="h2-..."`.
   - Текст: первый абзац — вводный, с ключевыми словами (название категории, Москва, iRepair-Store, купить/заказать). Включить **наиболее частотные и релевантные запросы** из этапа 1, естественно.
   - 3–4 секции с H2 и 1–2 абзацами; в конце блок `.irepair-seo-note` с кратким SEO-резюме (1–2 предложения).
   - Микроразметка: на корневой блок — `itemscope itemtype="https://schema.org/CollectionPage"`, `lang="ru"`. Внутри — `<meta itemprop="name">`, `<meta itemprop="description">` (до ~160 символов), `<link itemprop="url" href="https://irepair-store.ru/...">`.

3. **Перелинковка**  
   Использовать относительные URL по таблице из правила: `/`, `/kontakty/`, `/oplata-i-dostavka/`, `/mac/`, `/ipad/`, `/iphone/`, `/airpods/`, `/apple-watch/`, `/aksessuary/`; внешняя ссылка на сервис — `https://irepair.ru/` с `target="_blank" rel="noopener"`. Ссылки вставлять естественно в текст.

4. **Учёт конкурентов**  
   При формулировках H2, первого абзаца и блока «Почему купить у нас» учитывать структуру и мета конкурентов из этапа 1: не копировать, но закрывать те же интенты (доставка Москва, гарантия, оригинал, самовывоз и т.д.) и при необходимости использовать близкие по смыслу формулировки, улучшая их.

5. **Сохранение**  
   Сохранить результат в `категории/<Название категории>.html`. Имя файла — по названию категории (например `категории/MacBook Pro.html`).

6. **Мета для CS Cart**  
   В конец того же файла добавить блок-комментарий с рекомендациями:
   - **H1** — один на страницу, согласованный с текстом и ключевыми запросами.
   - **Title** — до ~55–60 символов, бренд (iRepair-Store) и гео (Москва) при необходимости.
   - **Description** — до ~155–160 символов, уникальная формулировка под Title и H1, в гармонии с `.irepair-seo-note` и `itemprop="description"`.
