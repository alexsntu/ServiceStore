## Шаблон комментария для CS Cart (в конец файла)

```html
<!--
  Рекомендации для страницы категории в CS Cart (согласованы с текстом выше):

  H1 (заголовок страницы, один на страницу):
  — формулировка, гармоничная с первым абзацем и ключевыми фразами.

  Title (тег <title>, до ~55–60 символов):
  — категория + «купить в Москве» / «iRepair-Store» и т.п.

  Description (meta name="description", до ~155–160 символов):
  — краткое описание для сниппета; уникальная формулировка под Title и H1.
-->
```

## Геопривязка

Все тексты и запросы — с учётом **Москва** (в Москве, купить в Москве, доставка по Москве, самовывоз в Москве).
